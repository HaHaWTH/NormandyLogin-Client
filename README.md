# Normandy Login

A Minecraft mod that provides secure authentication mechanism between client and server using RSA key pairs.

## Overview

Normandy Login is a Minecraft mod that enables secure authentication between clients and servers using cryptographic key pairs. The mod generates and manages RSA key pairs for each player-server combination, allowing for secure challenge-response authentication without transmitting sensitive information over the network.

## Features
- Secure Authentication: Uses RSA-2048 cryptography for secure authentication between client and server
- Automatic Key Management: Automatically generates, saves, and loads RSA key pairs per player-server combination
- Challenge-Response Protocol: Implements a secure challenge-response authentication flow
- Client-side storage: Private keys are stored under client directory `./.auth-token/servers/server-identifier/uuid.json`, sensitive information never gets transmitted over network.

## Mod Dependencies

- Fabric: Fabric API
- NeoForge: None

## FAQ

- Q: Is this safe?
- A: Yes, definitely. The key pairs are generated by the client, when the server requests an authentication, it will send a single-use 512-bit challenge to client.
If the client signed the challenge and has been verified by the server, then the client can safely login. This challenge-response mechanism can effectively guard against replay attacks.
